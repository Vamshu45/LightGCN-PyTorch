## What this project does

1. **Replication.** LightGCN is trained on Gowalla with the paper's settings. After 50 evaluated epochs Recall@20 = 0.1487 and NDCG@20 = 0.1239, about 80% of the published 0.1830 / 0.1554 (obtained with about 1000 epochs).
2. **Existing new dataset.** A 15,000-user subset of MovieLens-25M (ratings ≥ 4 as implicit positives, 10-core filtered).
3. **Newly constructed dataset.** GitHub stars crawled through the GitHub REST API: 180 users, 1,807 repositories, 14,282 interactions, usernames replaced by integer IDs, repositories enriched with metadata.
4. **Evaluation.** LightGCN against MF, popularity and random on held-out accuracy, plus an LLM-as-judge evaluation checked against 100 human labels.

## How to reproduce

### Option A: Google Colab (recommended)
Click the **Open in Colab** badge, set *Runtime → Change runtime type → T4 GPU*, and run the cells from top to bottom. The notebook's first table maps every section to the report.

### Option B: command line
```bash
git clone https://github.com/Vamshu45/LightGCN-PyTorch.git
cd LightGCN-PyTorch
pip install -r requirements.txt
cd code

# 1. Sanity check on LastFM (about 30 s on a GPU)
python main.py --decay=1e-4 --lr=0.001 --layer=3 --seed=2020 --dataset="lastfm" --topks="[20]" --recdim=64 --epochs=20 --tensorboard=0

# 2. Replication on Gowalla (Report Table 2)
python main.py --decay=1e-4 --lr=0.001 --layer=3 --seed=2020 --dataset="gowalla" --topks="[20]" --recdim=64 --epochs=60 --tensorboard=0

# 3. MovieLens-25M subset (Report Appendix Table 5); needs data/ml25m/ (see notebook Section 3)
python main.py --decay=1e-4 --lr=0.001 --layer=3 --seed=2020 --dataset="ml25m" --topks="[20]" --recdim=64 --epochs=60 --tensorboard=0

# 4. GitHub stars: LightGCN and MF, 300 epochs (Report Table 4, Figure 3)
python main.py --decay=1e-4 --lr=0.001 --layer=3 --seed=2020 --dataset="github" --topks="[20]" --recdim=64 --bpr_batch=256 --epochs=300 --tensorboard=0
python main.py --model=mf --decay=1e-4 --lr=0.001 --seed=2020 --dataset="github" --topks="[20]" --recdim=64 --bpr_batch=256 --epochs=300 --tensorboard=0

# 5. Recommendations and baselines (writes ../recs_*.json)
python gen_recs.py lgn
python gen_recs.py mf
```
The LLM-judge, statistical analysis and annotation steps are in notebook Sections 7 to 11. Cells that need a GitHub token, a Gemini key or a manual upload are marked **Re-running? Skip this cell** in the notebook; everything they produced (`gh_data/`, `judge_ratings.csv`, `results/`) is already in this repository, so all other cells run in a fresh Colab session.

## Expected results

| Experiment | Recall@20 | NDCG@20 |
|---|---|---|
| Gowalla, paper (~1000 epochs) | 0.1830 | 0.1554 |
| Gowalla, this replication (50 evaluated epochs) | 0.1487 | 0.1239 |
| MovieLens-25M subset (50 evaluated epochs) | 0.2625 | 0.2521 |
| GitHub stars, LightGCN (300 epochs) | 0.0526 | 0.0529 |
| GitHub stars, popularity | 0.0341 | 0.0358 |
| GitHub stars, MF | 0.0155 | 0.0133 |
| GitHub stars, random | 0.0072 | 0.0071 |

Single seed (2020); small differences between runs and GPUs are possible.

## Data and ethics
* The raw crawl (`github_raw.json`) contains real GitHub usernames and is **not** published. Only integer user IDs are released. This is pseudonymisation, not full anonymity.
* Repository metadata comes from the public GitHub REST API; repository descriptions belong to their authors.
* To re-run the crawl, use your own GitHub token.
* Generative AI assisted with code and drafting; the author is responsible for all outputs.
